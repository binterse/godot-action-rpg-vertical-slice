# godot-action-rpg-vertical-slice

Stridsystem is a Godot 4 sci-fi action RPG combat prototype built as a vertical slice.

## Workshop Context

This project was created as part of a hands-on workshop for learning how to build with AI, developed together by Björn and Per. The goal was to explore how AI can support game design, content generation, scripting, validation, and rapid prototyping inside a real Godot project.

## Run

- Double-click `run_game.bat`
- From PowerShell: `.\run_game.bat` or `.\run_game.ps1`
- Or launch Godot 4 and open this folder as the project.

## Validate

- Double-click `validate_project.bat`
- From PowerShell: `.\validate_project.bat` or `.\validate_project.ps1`
- Or run `godot --headless --path . --script res://tests/validate.gd`

## Controls

- `WASD`: move
- `Space`: dodge
- `Left Mouse`: light attack
- `Right Mouse`: heavy attack
- `E`: tech shot
- `C`: cleanse
- `Esc`: pause

## Content Targets

- 5 elements
- 4 status ailments
- 6 difficulties
- 12 habitats
- 255 generated enemy variants
